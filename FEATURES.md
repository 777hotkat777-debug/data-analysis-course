# FEATURES: витрина признаков (data/processed/features.parquet)

Одна строка витрины соответствует одному городу (1089 строк). Колонки после сдачи не переименовываются.

## Ключ и цели

| Колонка | Тип | Как получена |
|---|---|---|
| id_uc_g0 | int | ключ города из clean.parquet |
| pop_tot | float64 | численность населения города, 2025 (gh_pop_tot_2025), цель регрессии |
| pop_above_median | int8 | 1, если pop_tot выше медианы обучающей части (106 245), цель классификации |

## Отброшено при отборе

| Колонка | Источник | Причина |
|---|---|---|
| is_capital | категории | одно значение занимает 97.6% строк |
| tpa_municipal | текст | одно значение занимает 98.3% строк |
| tpa_forest | текст | одно значение занимает 98.6% строк |
| xst_a30_2025 | исходные числовые | |r| = 1.00 с gc_uca_km2_2025 |
| area_dev | агрегаты по группе | |r| = 1.00 с gc_uca_km2_2025 |
| tpa_des_len | текст | |r| = 0.97 с tpa_n |
| tpa_des_words | текст | |r| = 0.97 с tpa_n |

## Служебное

- Разбиение: функция split_mask в src/features.py, случайные 20% ключей в тест, seed 42.
- Отбор (доля одного значения больше 95%; |r| больше 0.9 внутри пары, остаётся первая по порядку колонка) считается только по обучающей части и без цели.
- Агрегаты по стране считаются по признакам всех строк, но без цели.
- Колонки с населением и производные от него (gh_pop_*, gc_pop_*, ex_*_pop, em_co2_pec) в признаки не входят.
